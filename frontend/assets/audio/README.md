# Placeholder audio files

Ces fichiers sont des placeholders. Remplacez-les par vos propres fichiers audio :

- `type.mp3` : Son joué lors de la saisie d'une lettre
- `delete.mp3` : Son joué lors de la suppression d'une lettre  
- `success.mp3` : Son joué quand un mot est trouvé

Format recommandé : MP3, durée courte (< 1 seconde pour type/delete, < 2 secondes pour success)
